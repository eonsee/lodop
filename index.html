控件与云打印如何选择？

由 LodopFuncs.js 中的 needCLodop() 根据浏览器 UA 自动判断。新版 Chromium 系列浏览器不再支持 NP 插件，会走 C-Lodop 云打印服务。

快速开始 · 02

三步开始打印

引入引导脚本 → 获取 LODOP 对象 → 初始化并添加打印项。以下代码可直接放入页面运行。

1

引入 LodopFuncs.js

把引导脚本作为统一的资源文件部署，所有页面共享一份，便于集中升级。

index.html
<script src="LodopFuncs.js"></script>
2

嵌入控件并获取对象

只保留 getLodop 一行，控件类型、安装检测与版本升级都交给引导脚本。

index.html
<object id="LODOP_OB" classid="clsid:2105C259-1E0C-4534-8141-A753534CB4CA" width="0" height="0">
  <embed id="LODOP_EM" type="application/x-print-lodop" width="0" height="0">
</object>
<script>
  var LODOP = getLodop(
    document.getElementById('LODOP_OB'),
    document.getElementById('LODOP_EM')
  );
</script>
3

初始化、添加内容、预览

一个完整的打印事务：设置任务名和纸张 → 添加打印项 → 预览或打印。

print.js
// 1. 初始化（任务名可为空）
LODOP.PRINT_INIT("订单系统_销售单");

// 2. 设置纸张：A4 纵向
LODOP.SET_PRINT_PAGESIZE(1, 0, 0, "A4");

// 3. 添加打印项
LODOP.ADD_PRINT_TEXT(20, 20, 300, 28, "销售出库单");
LODOP.SET_PRINT_STYLEA(0, "FontSize", 18);
LODOP.SET_PRINT_STYLEA(0, "Bold", 1);

LODOP.ADD_PRINT_TABLE(80, 20, "100%", 300,
  "<table border='1'><tr><td>商品</td><td>数量</td></tr>" +
  "<tr><td>打印纸</td><td>2</td></tr></table>");

// 4. 预览或直接打印
LODOP.PREVIEW();
关于直接打印

PRINT()、PRINTA()、PRINTB() 与 Excel 导出属于注册功能；未注册时仍可使用，但输出左下角会出现“本页由【试用版打印控件】输出”的水印。

参考 · 控件参数

三个控件参数

以页面 object 元素的 param 形式使用。控件默认宽高为 0 时完全隐藏。

Caption显示标题

设置控件的显示标题。希望预览或设计界面内嵌到网页时，用它标识控件位置。

<param name="Caption" value="我是打印控件lodop">
Color区域颜色

设置控件显示区域的底色，支持 #十六进制、RGB 十进制或英文颜色名，便于融入页面。

<param name="Color" value="#C0C0C0">
Border区域边界

设置显示区域是否有边界。1 为有边界，其它值无边界。

<param name="Border" value="1">

附录 · A

计量单位

所有位置与尺寸参数都支持整数（默认 px）或带单位的字符串。px 是固定换算单位，不受屏幕显示影响。

1 in 英寸 2.54 cm
1 in 英寸 25.4 mm
1 in 英寸 72 pt
1 in 英寸 96 px

书写规则

  • 整数默认长度为 px；但 SET_PRINT_PAGESIZE 的宽高默认是 0.1mm（45 表示 4.5mm）。
  • 字符串可带 in、cm、mm、pt、px、%，如 "10mm"。
  • 百分比上下边距与高度相对纸张高度；左右边距与宽度相对纸张宽度（横向打印时互换）。
  • 转义Width 可写 RightMargin:0.9cm，Height 可写 BottomMargin:9mm，从纸张另一侧定位。
等价写法
LODOP.ADD_PRINT_TEXT(11, 23, 98, 19, "单位 px");
LODOP.ADD_PRINT_TEXT("2.9mm", "6.1mm", "25.9mm", "5mm", "单位 mm");
LODOP.ADD_PRINT_TEXT("5%", "3%", "40%", "10%", "百分比");

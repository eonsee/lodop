# LODOP 技术文档站

基于《Lodop 技术手册 6.2.2.6》整理的单页技术文档站。参考 Element UI / Ant Design 的视觉语言，风格清新、操作直接，纯静态、零依赖、可离线使用。

## 使用

双击 `index.html` 即可在浏览器中打开，无需服务器、无需联网。

## 部署到 Vercel

仓库根目录就是站点根目录，不需要安装依赖或构建：

1. 在 [Vercel](https://vercel.com/new) 导入 GitHub 仓库 `eonsee/lodop`。
2. Framework Preset 选择 **Other**，Root Directory 保持仓库根目录。
3. Build Command 留空，Output Directory 填 `.`。
4. 点击 Deploy，之后每次推送到 `main` 都会自动部署。

`vercel.json` 已启用简洁 URL 并补充基础安全响应头。

## 内容

- **文档概览**：能力边界、快速导航
- **系统文件与安装**：4 个安装文件说明与下载入口
- **三步开始打印**：从引入控件到预览输出的完整流程
- **控件参数**：Caption / Color / Border 三个 object 参数
- **高阶能力**：6 个开放条目，突出跨页表格、打印设计器、模板复用、Excel/图片导出、打印行为控制与 RAW/端口直写；点击直达对应函数并展开
- **API 参考**：59 个函数，按初始化、打印项、输出控制、样式、打印设备、模式、数据与文件分类；16 个增强型函数带「增强」徽标，支持一键筛选；支持搜索、展开参数/返回值/示例
- **排版沙盒**：勾选打印元素，实时预览纸张布局并生成对应的 LODOP 代码，支持 A4 与小票 80mm
- **计量单位**、**注册与维护**

## 字体规范

字体系统参考 Ant Design、Material Design 3、IBM Carbon、GitHub Primer、Element Plus 与 Tailwind CSS 的排版约定，所有字号、行高、字重与字距均在 `assets/css/main.css` 的 `:root` 中定义，页面不直接写死 UI 字号。

| Token | 字号 | 行高 | 主要用途 |
| --- | --- | --- | --- |
| `--fs-display` | 32 → 46 | 1.15 | Hero 主标题 |
| `--fs-h2` | 24 → 30 | 1.25 | 章节标题 |
| `--fs-2xl` / `--fs-xl` | 20 / 18 | 1.25 | 统计数字、单位符号 |
| `--fs-lg` | 16 | 1.4 / 1.7 | 导语、条目标题 |
| `--fs-md` | 15 | 1.7 | 基础正文 |
| `--fs-base` | 14 | 1.6 | 表格、导航、次级正文 |
| `--fs-sm` | 13 | 1.6 | 列表描述、密集控件 |
| `--fs-xs` | 12 | 1.6 | 签名、注释、元信息 |
| `--fs-2xs` | 11 | 1.4 | 徽标、键帽、极小标签 |

- **字体族**：中文优先系统黑体（PingFang SC / HarmonyOS Sans SC / MiSans / Noto Sans SC / Microsoft YaHei），不加载 webfont；代码使用 JetBrains Mono → Cascadia Code → Consolas 回退。
- **字重**：仅使用 400 / 500 / 600 / 700，避免 650、750 等非标准字重。
- **字距**：标题 -0.02em，正文 0，全大写小标签 0.06em。
- **数字**：统计、计数、键帽与表格启用 `tabular-nums`，保证纵向对齐。
- **中文排版**：正文 15px / 1.7，段落启用 `text-wrap: pretty`，标题启用 `text-wrap: balance`；字号使用 rem，尊重浏览器字号设置。
- **例外**：Hero 插画与纸张预览中的微型文字按实际印刷比例使用 px，不参与 UI 字号阶梯。

## 布局原则

页面以「开放版式」为主，尽量减少卡片容器，让深海背景保持连续可见：

- 列表与栅格用发丝线（1px 上/下边框）分组，不使用圆角、阴影和实色卡片底。
- 悬停、展开等状态用极淡的表面着色或左侧强调线表达，不抬升元素。
- 代码块、纸张预览与表单控件因可读性需要保留必要的表面，但同样去掉圆角与重阴影。
- 排版依靠字号、字重、间距与对齐建立层级，而不是依赖容器。
